# ROOFF 회사 홈페이지

별도 빌드 없이 제공하는 한국어 정적 홈페이지입니다. 루트의 `index.html`을 사용하므로 기존 정적 호스팅 및 GitHub Pages 배포 구조를 유지합니다. 저장소에는 배포 워크플로와 CNAME이 없으며, 실제 GitHub Pages 설정은 이번 로컬 작업에서 변경하지 않았습니다.

## 수정 위치

- `index.html`: 서비스 소개, 출시일, 연락처, 검색·공유 메타데이터
- `assets/css/style.css`: 색상, 레이아웃, 반응형 스타일
- `assets/js/main.js`: 모바일 메뉴, 이메일 복사, 저작권 연도
- `assets/images/rooff-companions.webp`: 새 메인 이미지
- `assets/images/rooff-mark.svg`: 파비콘

외부 폰트와 JavaScript 라이브러리를 불러오지 않습니다. 과거 템플릿의 라이브러리 파일은 보관하지만 현재 페이지에서 사용하지 않습니다. 자바스크립트를 끈 상태에서도 콘텐츠, 메뉴 링크, 이메일 링크가 동작합니다.

## 로컬 확인

저장소 루트에서 `python -m http.server 8765 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:8765`를 엽니다. 정적 파일을 제공하는 다른 서버도 사용할 수 있습니다. 이메일 복사는 HTTPS 또는 localhost와 클립보드 권한이 필요하며, 사용할 수 없는 환경에서는 이메일 링크로 문의할 수 있습니다.

서비스 문구는 다음 로컬 프로젝트의 실제 코드에서 확인했습니다. 다른 프로젝트의 파일은 수정하지 않았습니다.

- `C:/PROJECTS/flutter/pet_mobile`: `lib/app_variant.dart`, `lib/routes.dart`, 품종 검색·분양 목록, 상담 채팅, 분양파트너·본인 인증, 신고 화면
- `D:/PROJECTS/server/pet_server`: 공공데이터 판매업 조회 API 및 채팅·신고 도메인

리뷰 기능과 익명 상담은 현재 확인한 앱 흐름에서 입증되지 않아 소개에서 제외했습니다. 서비스는 출시 준비 상태로 표시하며, 인증이 거래나 동물의 건강을 보증한다고 표현하지 않습니다. 기존 사업자등록번호는 유지했습니다.

실제 배포 주소가 저장소에서 확정되지 않아 canonical URL 및 절대 주소가 필요한 공유 이미지 URL은 임의로 넣지 않았습니다. 배포 주소 확정 후 해당 메타데이터를 추가할 수 있습니다.

## 검증

2026-09-17 로컬 Chrome / Playwright와 axe-core로 확인했습니다.

- 320, 390, 768, 900, 901, 1024, 1440px: 가로 넘침 없음, 이미지·내부 링크 정상
- 위 7개 너비의 WCAG 2 A/AA 및 2.1 AA 자동 점검: 탐지된 위반 0건
- 모바일 메뉴 열기·닫기, Escape, 초점 복귀, 섹션 이동 후 초점 확인
- 이메일 복사 성공·권한 거부 안내, 모션 감소 설정, JavaScript 비활성화 시 탐색 확인
- 본문 바로가기 키보드 이동, 브라우저 실행 오류·실패한 리소스 요청 없음
- 데스크톱·모바일 전체 페이지 스크린샷 시각 확인

자동 점검은 접근성 인증을 의미하지 않습니다. Safari·실기기와 실제 배포 환경은 별도 검증 대상입니다. 원격 저장소 push와 운영 배포는 수행하지 않았습니다.
